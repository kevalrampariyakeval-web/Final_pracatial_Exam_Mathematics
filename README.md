# 📊 Student Scores Analysis Project

This project analyzes the **students_scores.csv** dataset using Python to perform statistical analysis, probability calculations, data visualization, and basic linear algebra operations.

## 🔹 Project Tasks

* Calculate **Mean, Median, Mode** of Math Scores
* Find **Range, Variance, Standard Deviation** of Science Scores
* Compute **Probability of Passing**
* Create **Contingency Table** and **Conditional Probability**
* Plot **Histogram**, **Normal Curve**, and **Q-Q Plot**
* Calculate **Skewness** and **Kurtosis**
* Perform **Vector Operations** and **Linear Algebra Tasks**

## 🛠️ Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Jupyter Notebook

## 📁 Files Included

* `students_scores.csv` – Dataset
* `part_b_student_scores_analysis.ipynb` – Practical Implementation
* `part_a_theory_answers.pdf` – Theory Answers

## ▶️ How to Run

1. Open the notebook in Jupyter/VS Code
2. Keep dataset in the same folder
3. Run all cells step by step

This project demonstrates practical understanding of **Statistics, Probability, Data Visualization, and Linear Algebra using Python**.
